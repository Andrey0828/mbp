# Моделирование бизнес-процессов

Интерактивный тест из 212 вопросов. Работает в браузере без установки зависимостей и подключения к интернету.

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере.

## Возможности

- Поиск по номеру, тексту вопроса и вариантам ответа.
- Одиночный выбор, задания на соответствие и ввод ответа.
- Мгновенная проверка при выборе radio-ответа; для соответствий и ввода текста — кнопка проверки.
- Сохранение ответов и результатов проверки в текущем браузере.
- Закреплённая панель «Назад / Проверить ответ / Дальше» над вопросом: кнопки сохраняют положение при переходах и раскрытии ответа.
- Кнопка «Показать все ответы»: все вопросы с ответами по порядку на одной странице.
- Отдельная кнопка сброса прогресса с подтверждением.
- Пометки для гипотез и вопросов с отсутствующими изображениями.
- Учебные SVG-иллюстрации к 31 вопросу с пропавшими изображениями: в вопросе до выбора, после проверки и в режиме всех ответов.

## Ключи ответов

Для 187 вопросов ответы выбраны по максимальному числу голосов в предоставленной статистике. Метки правильности исходного сервиса не учитывались. При равенстве голосов принимается любой из лидеров.

Ещё 7 вопросов дополнены гипотезами, выделенными отдельно. Для 18 вопросов ключ не восстановлен из-за отсутствующих изображений; они не участвуют в оценке.

Просмотр всех ответов не заполняет тест и не изменяет результат попытки.

## Иллюстрации

Картинки добавлены к вопросам с однозначным лидером голосования, отмеченным в PDF как правильный. Для 11 остальных вопросов со статистикой и пропавшими изображениями показаны пояснения о ничьей или отсутствии подтверждения. Ключи ответов остались прежними.

Это учебные перерисовки обозначений и примеры по лекциям курса, а не восстановленные оригиналы PDF. Включены события и задачи BPMN, операторы и элементы ARIS/eEPC, стрелки IDEF0 и пример иерархии функций. Встроенные SVG работают без интернета; подписи и альтернативный текст поясняют каждый рисунок.

Картинки в вопросах выделены светло-фиолетовым фоном и подписью «Создано по ответу».

## Структура

`index.html` содержит интерфейс, стили, логику и все вопросы. Сервер, сборка и внешние библиотеки не требуются.
